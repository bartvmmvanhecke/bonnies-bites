# Bonnie’s Bites

Frisse community-preview voor koken, met de kids, eropuit en kleine gelukjes.

- `npm run dev` start de lokale site.
- `npm run build` maakt de productieversie in `dist`.
- `npm run preview` toont de build.

De oorspronkelijke recepten staan in `data/recipes.json`; aanvullende bestaande recepten staan in `js/recipe-library.js`. `js/app.js` verzorgt ontdekken, filteren, details, favorieten en de lokale inzendflow.

Nieuwe niet-recepttips zijn voorbeeldcontent. Bijdragen en favorieten worden alleen lokaal bewaard, niet verzonden of openbaar gedeeld. Voor een communitylancering zijn gedeelde opslag en moderatie nodig.
